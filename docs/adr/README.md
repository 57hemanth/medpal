# Architecture Decision Records

Each ADR records one decision: the constraint that forced it, the options weighed, what was chosen, what got **harder** because of it, and when to revisit it. They're short on purpose. Read them to understand *why* the code looks the way it does.

| ADR | Decision |
|---|---|
| [0001](0001-modular-monolith.md) | One deployable service with strict module boundaries, not microservices |
| [0002](0002-orchestration-langgraph.md) | Workflows are LangGraph graphs with a Postgres checkpointer |
| [0003](0003-row-level-security.md) | Patient-data isolation is enforced by Postgres row-level security, under a non-superuser app role |
| [0004](0004-generated-directory-in-code.md) | The doctor directory and slot calendar are generated by seeded code, not an LLM |
| [0005](0005-booking-concurrency.md) | Bookings use an advisory lock, a capacity check and client idempotency keys |
| [0006](0006-presidio-deidentification.md) | Microsoft Presidio, extended for India, de-identifies text before it leaves the boundary |
| [0007](0007-exact-vector-search-per-patient.md) | Records retrieval uses an exact pgvector scan scoped to one patient, with no ANN index |
| [0008](0008-hybrid-deployment-egress-boundary.md) | Hybrid deployment: internal network with no route out, one ingress, one allowlisting egress proxy |
| [0009](0009-async-ingest-parallel-pages.md) | Records ingest on a queue; pages processed in parallel; privacy scan stays at upload |
| [0010](0010-structured-safety-screen.md) | A structured yes/no safety screen, not free-text rules, is the emergency gate |
| [0011](0011-in-boundary-tracing.md) | Tracing and cost metering in Postgres, metadata only |
| [0012](0012-supervisor-with-specialist-graphs.md) | A supervisor that delegates to specialist graphs running as their own threads |
| [0013](0013-model-step-in-triage.md) | One bounded, prefetched model step in triage: red flags may only be added; specialty only when the rules are unsure |

Format: **Status · Context · Options · Decision · Revisit trigger · Consequences (easier / harder) · Proof · Checked on**.
